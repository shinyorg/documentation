## Overview

Azure Notification Hubs provides tag-based targeting, templates, and enterprise-scale push management across iOS, Mac Catalyst, macOS and tvOS (APNs), Android (FCM v1), and Windows (WNS).

:::note[macOS and tvOS]
A hub's Apple (APNs) settings carry a single bundle ID, which becomes the APNs topic. A macOS or tvOS app that has its own bundle ID needs its own hub; apps sharing one bundle ID through universal purchase can share a hub. tvOS can only receive silent (`content-available`) or badge-only pushes, so send those payloads to tvOS installations.
:::

```csharp
services.AddPushAzureNotificationHubs<MyPushDelegate>(
    "Endpoint=sb://your-hub.servicebus.windows.net/;SharedAccessKeyName=DefaultListenSharedAccessSignature;SharedAccessKey=your-key",
    "your-hub-name"
);
```

## With Custom Firebase Config (Android)

```csharp
#if ANDROID
services.AddPushAzureNotificationHubs<MyPushDelegate>(
    "your-connection-string",
    "your-hub-name",
    new FirebaseConfig(
        UseEmbeddedConfiguration: false,
        AppId: "your-app-id",
        SenderId: "your-sender-id",
        ProjectId: "your-project-id",
        ApiKey: "your-api-key"
    )
);
#else
services.AddPushAzureNotificationHubs<MyPushDelegate>(
    "your-connection-string",
    "your-hub-name"
);
#endif
```

## Customizing the Installation

Use `IPushInstallationEvent` to modify the Azure Notification Hubs installation before it's sent.

```csharp
public class MyInstallationEvent : IPushInstallationEvent
{
    public Task OnBeforeSend(Installation installation)
    {
        // Add custom tags
        installation.Tags ??= new List<string>();
        installation.Tags.Add("custom-tag");

        // Add templates
        installation.Templates ??= new Dictionary<string, InstallationTemplate>();
        installation.Templates["myTemplate"] = new InstallationTemplate
        {
            Body = "{\"data\":{\"message\":\"$(message)\"}}"
        };

        return Task.CompletedTask;
    }
}
```
