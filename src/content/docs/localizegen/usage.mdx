## Code-Behind

```csharp
var localizer = services.GetRequiredService<MyViewModelLocalized>();

// Simple string property
Console.WriteLine(localizer.Welcome);

// Format string method
Console.WriteLine(localizer.UserGreetingFormat("Allan", "MyApp"));
// Output: Hello Allan, welcome to MyApp!
```

## XAML Binding (MAUI)

```xml
<Label Text="{Binding Localizer.Welcome}" />
```

## Blazor / Razor

```razor
@inject MyViewModelLocalized Localizer

<h1>@Localizer.Welcome</h1>
<p>@Localizer.UserGreetingFormat(User.Name, "MyApp")</p>
```

## Raw Localizer Access

The generated class exposes the underlying `IStringLocalizer` for edge cases:

```csharp
// Dynamic key lookup when you need it
var value = localizer.Localizer["SomeDynamicKey"];
```

## Enumerating Localizers

The generator writes a `GeneratedLocalizers` class next to `AddStronglyTypedLocalizations()`, with one entry per `.resx` file:

| Field | Description |
|-------|-------------|
| `Name` | The `.resx` file name without its extension, e.g. `MyViewModel` or `Errors.Validation` |
| `ResourceSource` | The `T` used with `IStringLocalizer<T>` |
| `LocalizedType` | The generated wrapper, e.g. `MyViewModelLocalized` |

Use it when you need to look localizers up by name, such as in a XAML markup extension (`{loc:T MyViewModel.Welcome}`). It contains no reflection, so it is safe under trimming and NativeAOT:

```csharp
var factory = services.GetRequiredService<IStringLocalizerFactory>();
var byName = GeneratedLocalizers.All.ToDictionary(
    x => x.Name,
    x => factory.Create(x.ResourceSource)
);

var welcome = byName["MyViewModel"]["Welcome"];
```

`GeneratedLocalizers` lives in your project's root namespace. Each project that uses the generator gets its own copy listing only its own resources.

## Visibility

Each generated `*Localized` class matches the visibility of its paired class: a `public` class gets a `public` localizer and an `internal` class an `internal` one. You can mix internal services and public Blazor components in the same project.

`GenerateLocalizersInternal` applies when there is no paired class to follow: the classes the generator creates for you, and the `AddStronglyTypedLocalizations()` and `GeneratedLocalizers` classes:

```xml
<PropertyGroup>
    <GenerateLocalizersInternal>True</GenerateLocalizersInternal>
</PropertyGroup>
```
