## 1.0 - October 12, 2026

<RN type="feature">Initial release. Ports of the Shiny HTTP Server add-ons to ASP.NET Core: WebDAV, CalDAV/CardDAV, tus resumable uploads, file sync, NuGet feed, npm registry, DocumentDb REST/SSE endpoints, JSON Patch, webhooks, idempotency keys, Content-Digest, ACME automatic TLS, mDNS discovery, SSH tunnels and cloudflared/ngrok/Tailscale tunnel agents</RN>

<RN type="breaking">`Shiny.Extensions.WebHosting` moved here as [`Shiny.AspNet.WebHosting`](/aspnet/webhosting/). Only the package name changed — `IWebModule`, `AddInfrastructureModules` and `UseInfrastructureModules` are the same, in the `Shiny` namespace</RN>
