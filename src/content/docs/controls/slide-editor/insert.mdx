What the **Insert** tab adds beyond shapes, pictures, tables and text boxes (those are on
[Objects, Groups & Tables](/controls/slide-editor/objects/)).

## Charts

Column, bar, line and pie, entered through a **data-grid dialog**. A chart is drawn by Skia and written as
a real `c:chartSpace` with its caches, so PowerPoint shows it — but with **no embedded workbook**. A contextual **Chart Design** tab appears while one is
selected.

```csharp
var c = editor.Controller!;

c.AddChart(chart);        // a SlideChart
c.SetChartData(...);
```

## Icons

Insert ▸ Illustrations ▸ **Icons** places an icon on the slide.

```csharp
c.AddIcon(...);
```

## Audio and video

Insert ▸ **Media** embeds an audio or video file with a **poster frame**. The slide show plays it on tap,
through the host — a browser element on Blazor, the platform launcher on MAUI — rather than inline on the
slide.

```csharp
c.AddMedia(bytes, "video/mp4", isVideo: true, poster);
```

## Date, time, slide number and Header & Footer

Insert ▸ Text adds **Date & Time** and **Slide Number** fields; **Header & Footer** opens a dialog for
the date, slide number and footer text, applied to this slide or all.

```csharp
c.InsertField(SlideFieldKind.SlideNumber);
c.ApplyHeaderFooter(headerFooter, applyToAll: true);   // a SlideHeaderFooter
```
