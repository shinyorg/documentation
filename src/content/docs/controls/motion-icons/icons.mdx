Every built-in icon carries motion authored for that icon specifically. That is the difference between a motion icon and an icon with an animation applied to it: a trash can's lid lifts off its hinge, a download arrow falls out of the tray and reappears above it, a signal meter lights from the handset outwards.

Names are one flat, case-insensitive namespace — the groups below only exist to make the list readable, and nothing in the API is grouped.

| Icon | Motion |
|---|---|
| `add-user` | The badge spins a quarter turn as it pops. A plus is symmetric every 90°, so it lands on itself. |
| `attach` | The clip swings and lifts, hinged at the top of its own loop. |

| `close` | Rotates a half turn — which lands the cross back on itself — while both strokes wipe off and back on. |
| `copy` | The front sheet slides off the back one and returns. |

| `edit` | The pencil writes while the line draws itself in underneath. |
| `filter` | Settles vertically, like something poured through it. |
| `link` | The two halves pull apart while the bar between them wipes out, then snap back together. |
| `loader` | Turns while its arc trims, so the ring appears to chase its own tail. |
| `logout` | The arrow leaves through the door, vanishes, and comes back in behind it. |
| `menu` | Morphs into a cross and back. Each bar spins about its own centre, then slides to the middle. |
| `more` | Three dots bounce in sequence. |
| `pin` | The head rocks while the needle draws itself down. |
| `plus` | A quarter turn with an overshoot. A plus is symmetric every 90°, so it can afford to. |
| `power` | The stem draws, then the arc closes around it, then the whole thing pulses. |

| `save` | The whole body presses in and springs back; the label nudges down with it. |

## Navigation

Every arrow travels the way it points and pulls its shaft in behind the head; every chevron bounces once in its own direction. Swapping `arrow-right` for `arrow-left` in a right-to-left layout therefore gets the mirrored motion for free.

| Icon | Motion |
|---|---|
| `arrow-left` | Travels left while its shaft retracts behind the head. |
| `arrow-right` | Travels right while its shaft retracts behind the head. |
| `arrow-up` | Travels up while its shaft retracts behind the head. |
| `arrow-down` | Travels down while its shaft retracts behind the head. |
| `chevron-up` | Bobs upward, landing with a bounce. |
| `chevron-down` | Bobs downward, landing with a bounce. |
| `chevron-left` | Bobs left, landing with a bounce. |
| `chevron-right` | Bobs right, landing with a bounce. |
| `expand` | The four corner brackets push outward and settle. |
| `collapse` | The same four pull inward. |
| `external-link` | The arrow leaves the frame on its own diagonal and returns while the frame recoils. |
| `compass` | The needle settles the way a real one does — a wide first swing, then progressively smaller ones. |

## Listing them at runtime

```csharp
foreach (var name in MotionIconLibrary.Names)
    Console.WriteLine(name);

var bell = MotionIconLibrary.Get("bell");        // throws if missing
var maybe = MotionIconLibrary.Find("bell");      // null if missing
```

Lookup is case-insensitive. `MotionIconLibrary.All` gives you the definitions themselves, which is how the sample app builds its gallery.

## Overriding one

`Register` replaces a built-in as well as adding a new one, so an app with its own visual language can swap the artwork for `check` once at startup instead of passing a definition in at every call site:

```csharp
MotionIconLibrary.Register(new MotionIconDefinition(
    "check",
    [new MotionIconPart("mark", "M5 13L10 18L19 6")],
    MotionSpecBuilder.Build(400, m => m
        .Trim("mark", k => k.At(0d, 0d, MotionEase.CubicOut).At(1d, 1d)))));
```

Every `Icon="check"` in the app picks it up.
