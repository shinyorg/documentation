Word's **Home** tab, on both hosts. Every command is a `DocumentEditorController` method first, so a host
with its own chrome gets the same behaviour.

## Clipboard and Format Painter

`Copy()` / `Cut()` return the plain text for the system clipboard and keep a formatted copy.
`Paste(systemText)` pastes that copy **with its formatting** when the system clipboard still holds what
was copied here, and pastes plain text otherwise. `PasteText` is **Keep Text Only** (newlines become
paragraphs). Comment anchors, bookmarks and footnote references are left out of a copy, since they are
unique per document.

On MAUI the surface's `CopyAsync` / `CutAsync` / `PasteAsync` go through `Clipboard.Default`; on Blazor
through `navigator.clipboard` and the browser's paste event.

**Format Painter** (`CopyFormatting(sticky)`, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> /
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd>): pick up the caret's formatting, then select text — the
paint happens when the selecting gesture ends (`CompletePointerGesture`). A selection covering whole
paragraphs takes their paragraph formatting too.

## Font and Paragraph

| | |
|---|---|
| `GrowFont` / `ShrinkFont` | Word's size steps (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>&gt;</kbd> / <kbd>&lt;</kbd>) |
| `ChangeCase(TextCase)` | Sentence / lower / UPPER / Capitalize / tOGGLE; <kbd>Shift</kbd>+<kbd>F3</kbd> cycles |
| `ToggleSubscript` / `ToggleSuperscript` | <kbd>Ctrl</kbd>+<kbd>=</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>=</kbd> |
| `ClearFormatting` | Direct character formatting off, paragraphs back to Normal (lists kept) |
| `SetLineSpacing(1.15)`, `SetParagraphSpacing(before, after)` | Multiples of single; spacing in points (<kbd>Ctrl</kbd>+<kbd>1</kbd> / <kbd>5</kbd> / <kbd>2</kbd>) |
| `ChangeIndent(±1)`, `SetIndents(left, right, firstLine)` | Half an inch per press for ordinary paragraphs (a list item moves a level); a negative first line is a hanging indent |
| `SetParagraphShading(color)`, `SetParagraphBorders(preset)` | Drawn and saved (`w:shd`, `w:pBdr`) |
| `ShowFormattingMarks` | Pilcrows and space dots — a view setting, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>8</kbd> |

`TextCase` is shared with the slide editor (`Shiny.Controls.Office.Text`).

Every run and paragraph property is written at its schema position — `w:rPr` and `w:pPr` are sequences,
and a `w:color` after a `w:u` is a file Word calls corrupt — which the test suite checks by
schema-validating every feature's saved output.

Indents and tab stops can also be dragged on the [ruler](/controls/office-shell/#ruler) above the page;
see [Page Layout & Views](/controls/document-editor/page-layout/#tab-stops-and-the-ruler).

## Styles

Home ▸ Styles is the "AaBbCcDd" gallery (`OfficeStyleGallery`, a [RibbonGallery](/controls/ribbon/#galleries)),
and this is the API it binds to:

```csharp
IReadOnlyList<DocumentStyleInfo> styles = c.AvailableStyles;  // Id, Name, FontFamily, FontSize (pt), Color, Bold, Italic, OutlineLevel
string current = c.CurrentStyleId;                           // also CaretFormat.StyleId
c.ApplyStyle("Heading2");                                    // creates Word's definition when the document lacks it
c.CurrentStyleChanged += ...;                                // the caret moved onto a different style
```

`AvailableStyles` is Word's gallery set — Normal, No Spacing, Heading 1-3, Title, Subtitle, Quote,
Intense Quote, List Paragraph — followed by the document's own visible paragraph styles, each with the
formatting to preview it in. Applying a built-in the document does not define writes Word's own
definition (ids, names, `basedOn` chain) into `styles.xml` first, so it shows in Word's gallery by its
usual name. <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd>..<kbd>3</kbd> apply the headings and
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> Normal.

## Find and Replace

<kbd>Ctrl</kbd>+<kbd>H</kbd> (Home ▸ Editing ▸ Replace) opens Replace: Find Next, Replace, Replace All,
with Match case and Whole words. **Replace All is one undo step**, and the replacement keeps the
formatting of the text it replaces. Find and Replace both cover table cells.

```csharp
c.Find.Query = "colour";
c.ReplaceCurrent("color");                       // replaces the hit the selection is on, steps on
var n = c.ReplaceAll("colour", "color", new FindOptions { MatchCase = true });
```

The find box itself — the `3/12` readout, wrapping and keys — is described on
[Find in Office Documents](/controls/office-find/).
