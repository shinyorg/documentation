Display text whose letters are windows onto a looping video, in the style of Magic UI's [video text](https://magicui.design/docs/components/video-text). The video plays only inside the glyphs. Everything around them is **transparent**, so whatever is behind the control shows between the letters.

It's a decorative control. There's **no transport bar**, no seeking and no fullscreen. The video starts as soon as it opens and loops forever, and **sound is off** until you turn it on.

VideoText ships in the MediaElement packages and uses the same player:

## MAUI

`UseShinyMediaElement()` registers the handler:

```csharp
builder
    .UseShinyControls()
    .UseShinyMediaElement();
```

```xml
<ContentPage xmlns:media="http://shiny.net/maui/media">

    <media:VideoText Source="https://example.com/ocean.mp4"
                     Text="OCEAN"
                     HeightRequest="200" />

    <!-- two lines, a fixed size, and sound on -->
    <media:VideoText Source="intro.mp4"
                     Text="BIG&#10;WAVES"
                     FontSize="72"
                     FontFamily="OpenSansSemibold"
                     IsMuted="False"
                     HeightRequest="200" />
</ContentPage>
```

| Property | Default | Description |
|---|---|---|
| `Source` | `null` | The video, as a `MediaSource`. A string is read as a URI, a file path or a `Resources/Raw` asset, the same as on `MediaElement` |
| `Text` | `null` | The text cut out of the video. Only explicit line breaks (`&#10;`) split it; it's never wrapped |
| `FontSize` | `0` | **`0` auto-fits** the text to 90% of the control on its tighter axis. Any other value is a fixed size |
| `FontFamily` | system | A registered MAUI font alias or a platform font name |
| `FontAttributes` | `Bold` | Thin strokes show very little video |
| `IsMuted` | `true` | Set to `False` for sound |
| `FallbackTextColor` | label default | The text colour on platforms with no masked output (see below) |

The video always **covers** the control (AspectFill). Size the control to the box you want the text in. To show something between the letters, put a background (a gradient or an image) on a parent, not on the control.

### Platform support

On each platform VideoText puts a native mask over the same player that `MediaElement` uses:

| Platform | How it's drawn |
|---|---|
| iOS, Mac Catalyst | A `CALayer` mask with the text rendered into it, on the `AVPlayerLayer` |
| macOS (AppKit) | The same, rendered through a `CGBitmapContext` |
| Android | ExoPlayer renders into a `TextureView`, and the text is composited over it with `DST_IN` in its own layer |
| Windows, Linux (GTK4) | **No mask yet.** The text is shown in `FallbackTextColor` and no video is loaded. `VideoText.IsMaskSupported` tells you which you got |

Android needs a `TextureView` because Media3's default `SurfaceView` is a separate window surface, and nothing drawn in the view hierarchy can mask it.

## Blazor

```razor
@using Shiny.Blazor.Controls.Media

<div style="background:linear-gradient(135deg,#0f172a,#1e1b4b);">
    <VideoText Source="https://example.com/ocean.mp4"
               Text="OCEAN"
               Style="height:220px;" />
</div>
```

| Parameter | Default | Description |
|---|---|---|
| `Source` | `null` | Video URL |
| `Text` | `null` | `\n` starts a new line |
| `FontSize` | `0` | CSS pixels. `0` auto-fits |
| `FontFamily` | `sans-serif` | A **system** font or a generic family (see below) |
| `FontWeight` | `bold` | Any CSS `font-weight` |
| `FontStyle` | `null` | For example `italic` |
| `IsMuted` | `true` | |
| `Preload` | `auto` | The video's `preload` hint |
| `CssClass` / `Style` | | The container is 200px tall by default. Your `Style` is added after the mask, so it never replaces it |

The text is an SVG used as a CSS `mask-image`. For auto-fit, the browser measures the glyphs and the component sizes the SVG's `viewBox` to them. The mask then scales with the container, so no resize observer is needed.

:::caution[Things to know]
- **Web fonts don't reach the mask.** An SVG loaded as an image can't see the page's `@font-face` fonts, so a web font falls back to a system font without any error. Use an installed font or a generic family.
- **Sound needs a user gesture.** Browsers block autoplay with sound until the user has interacted with the page. With `IsMuted="false"`, a blocked `play()` falls back to muted playback, so the letters keep moving instead of freezing.
:::
