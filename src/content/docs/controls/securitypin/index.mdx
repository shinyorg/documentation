A PIN entry control with individually rendered cells that captures input through a hidden Entry. Digits are visible by default and can optionally be masked with any character for password-style entry.

## Basic Usage

```xml
<!-- Visible 4-digit numeric PIN -->
<shiny:SecurityPin Length="4"
                   Value="{Binding Pin}"
                   Keyboard="Numeric" />

<!-- Masked 6-digit PIN with '*' -->
<shiny:SecurityPin Length="6"
                   HideCharacter="*"
                   Value="{Binding Pin}"
                   Keyboard="Numeric" />

<!-- Alphanumeric PIN masked with bullets -->
<shiny:SecurityPin Length="5"
                   HideCharacter="●"
                   Value="{Binding Pin}"
                   Keyboard="Default" />
```

## Completion Event

```xml
<shiny:SecurityPin x:Name="Pin"
                   Length="4"
                   Value="{Binding Pin}"
                   Completed="OnPinCompleted" />
```

```csharp
void OnPinCompleted(object? sender, SecurityPinCompletedEventArgs e)
{
    var enteredValue = e.Value;
    // verify the PIN
}
```

## Properties

| Property | Type | Default | Description |
|---|---|---|---|
| `Length` | `int` | `4` | Number of PIN cells |
| `Value` | `string` | `""` | Current PIN value (TwoWay) |
| `Keyboard` | `Keyboard` | `Numeric` | Keyboard type for input |
| `HideCharacter` | `string?` | `null` | When set, masks entered characters; when null or empty, shows actual values |
| `CellSize` | `double` | `50` | Width/height of each cell |
| `CellSpacing` | `double` | `8` | Space between cells |
| `CellCornerRadius` | `double` | `8` | Border corner radius |
| `CellBorderColor` | `Color?` | `null` | Cell border color |
| `CellFocusedBorderColor` | `Color?` | `null` | Border color for the active cell; unset uses the theme's `primary` |
| `CellBackgroundColor` | `Color?` | `null` | Cell fill color |
| `CellFocusedBackgroundColor` | `Color?` | `null` | Fill of the active cell; unset keeps `CellBackgroundColor` |
| `CellTextColor` | `Color?` | `null` | Entered character color |
| `CellFocusedTextColor` | `Color?` | `null` | Character color of the active cell; unset keeps `CellTextColor` |
| `CellBorderThickness` | `double` | theme thin (1) | Cell stroke width |
| `CellFocusedBorderThickness` | `double` | unset | Stroke width of the active cell; unset keeps `CellBorderThickness` |
| `CellBorderStyle` | `SecurityPinBorderStyle` | `Solid` | `Solid`, `Dashed`, `Dotted` or `None` |
| `CellFocusedBorderStyle` | `SecurityPinBorderStyle?` | `null` | Stroke style of the active cell; unset keeps `CellBorderStyle` |
| `HighlightCurrentCell` | `bool` | `true` | Turn off to draw the active cell like the others |
| `FontSize` | `double` | `24` | Character font size |
| `UseFeedback` | `bool` | `true` | Haptic click on each digit entry, long-press on completion |

## Events

| Event | Args | Description |
|---|---|---|
| `Completed` | `SecurityPinCompletedEventArgs` | Fires when the entered value length reaches `Length` |

## Methods

| Method | Description |
|---|---|
| `Focus()` | Focus the hidden Entry and bring up the keyboard |
| `Unfocus()` | Dismiss the keyboard |
| `Clear()` | Reset the value to empty |

## Highlighting the Current Cell

While the pin has focus, the cell waiting for the next character (the first empty one, or the last cell once the pin is full) takes the `CellFocused…` appearance. Each `CellFocused…` property left unset falls back to its plain `Cell…` twin, except the border color, which falls back to the theme's `primary`. Set `HighlightCurrentCell="False"` to draw every cell the same.

```xml
<shiny:SecurityPin Length="4"
                   CellBorderStyle="Dashed"
                   CellFocusedBorderStyle="Solid"
                   CellFocusedBorderThickness="3"
                   CellFocusedBorderColor="DarkOrange"
                   CellFocusedBackgroundColor="#FFF3E0"
                   CellFocusedTextColor="DarkOrange" />
```

```razor
<SecurityPin @bind-Value="pin"
             Length="4"
             CellBorderStyle="SecurityPinBorderStyle.Dashed"
             CellFocusedBorderStyle="SecurityPinBorderStyle.Solid"
             CellFocusedBorderThickness="3"
             CellFocusedBorderColor="#F97316"
             CellFocusedBackgroundColor="#FFF3E0"
             CellFocusedTextColor="#C2410C" />
```

On Blazor the active cell also gets a focus ring. Override the `--shiny-pin-focus-ring` CSS custom property with any `box-shadow` value, or `none`, to change or drop it.

## Behavior Notes

- A hidden `Entry` captures keyboard input; tapping any cell focuses it and brings up the keyboard
- `MaxLength` on the internal Entry is kept in sync with `Length`
- Changing `Length` rebuilds the cells; a longer `Value` is truncated
- The cell awaiting the next character is highlighted while the pin has focus (see above)
- When `HideCharacter` is null or empty, the actual entered character is displayed

## Blazor Usage

```razor
@using Shiny.Blazor.Controls

<SecurityPin Length="4"
             HideCharacter="●"
             Value="@pin"
             ValueChanged="v => pin = v"
             Completed="OnCompleted"
             CellSize="48"
             CellSpacing="10"
             CellCornerRadius="12"
             CellBorderColor="#D1D5DB"
             CellFocusedBorderColor="#3B82F6"
             CellBackgroundColor="#F5F5F5"
             CellTextColor="black" />

@code {
    string pin = "";

    void OnCompleted(string value)
    {
        // Verify the PIN
    }
}
```

:::note
On Blazor, colors are CSS strings. `Value` uses `ValueChanged` callback for two-way binding. `Completed` is `EventCallback<string>` instead of an event with `SecurityPinCompletedEventArgs`. `Keyboard` is not applicable on Blazor.
:::
