**Insert ▸ Charts** — column, bar, line, pie and area — charts the selection.

```csharp
controller.InsertChart(ChartKind.Column, "Units");
```

Charts are real DrawingML: a `c:chartSpace` in a drawing, anchored to cells, so Excel opens them as its
own. They are drawn by a Skia `ChartPainter` over the grid on both hosts.

On the grid a chart behaves like an object:

| | |
|---|---|
| **Click** | Selects it |
| **Drag** | Moves it |
| **Corner handles** | Resize it |
| **Delete** | Removes it |

Each is one undo step. Series references follow inserted and deleted rows, like every other reference in
the sheet.

:::note[Charts from Excel files]
Charts in a workbook authored in Excel render with default styling — only the type, series and title
are read. The chart parts themselves are preserved untouched on save.
:::
