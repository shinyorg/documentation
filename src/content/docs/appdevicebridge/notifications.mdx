The notifications bridge sends local notifications now, on a schedule, repeating or at a geofence, lists and cancels pending ones, sets the badge and manages channels. A tap reaches the page, or background.js when no page is open. It's backed by Shiny.Notifications.

Android, iOS, Mac Catalyst, macOS, Windows, and Linux through Shiny.Notifications.Linux.

## Install and register

```bash
dotnet add package Shiny.AppDeviceBridge.Notifications
```

```csharp
builder.UseAppDeviceBridge(
    bridge => bridge.AddNotificationsBridge(),
    webApp => { /* … */ }
);
```

| Client | C# | TypeScript |
| --- | --- | --- |
| `INotificationsBridge` | `AddNotificationsBridgeClient()` | `NotificationsBridge` |
