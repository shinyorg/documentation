The notifications bridge sends local notifications now, on a schedule, repeating or at a geofence, lists and cancels pending ones, sets the badge and manages channels. A tap reaches the page, or background.js when no page is open. It's backed by Shiny.Notifications.

Android, iOS, Mac Catalyst, macOS, Windows, and Linux through Shiny.Notifications.Linux.

## Install and register

```bash
dotnet add package Shiny.AppDeviceBridge.Notifications
```

```csharp
builder.UseAppDeviceBridge(
    bridge => bridge.AddNotificationsBridge(),
    webApp => { /* … */ }
);
```

| Client | C# | TypeScript |
| --- | --- | --- |
| `INotificationsBridge` | `AddNotificationsBridgeClient()` | `NotificationsBridge` |

## From the page

What `send` takes, and how taps reach background.js, is on [Native Calls & Background](/appdevicebridge/background/).

```ts
import { NotificationsBridge } from "@shinyorg/appdevicebridge";

const notifications = new NotificationsBridge();
await notifications.requestAccess({ timeSensitive: false });

const { id } = await notifications.send({
    title: "Order ready",
    message: "Table 12 is up",
    scheduleDate: new Date(Date.now() + 60_000),
    data: { order: "1234" }
});

await notifications.onEntry(n => navigate(`/orders/${n.data.order}`));   // the user tapped it
await notifications.setBadge({ value: 3 });
```

## Channels and actions

A channel can carry action buttons. `requiresUnlock` makes the user unlock the device before the action runs — use it
for actions with a real-world effect, such as opening a garage door. It applies on iOS, Mac Catalyst and macOS, and on
Android 12 and later; older Android versions run the action without asking, and Windows and Linux ignore it.

```ts
await notifications.addChannel({
    identifier: "garage",
    actions: [
        { identifier: "open", title: "Open Garage", actionType: "OpenApp", requiresUnlock: true },
        { identifier: "dismiss", title: "Dismiss", actionType: "Destructive", requiresUnlock: false }
    ]
});
```

The tapped action reaches `notification.entry` as `action`.
