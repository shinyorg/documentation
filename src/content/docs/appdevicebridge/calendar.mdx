The calendar bridge lists the device's calendars and their events in a date range, and creates, updates and deletes events.

## Install and register

```bash
dotnet add package Shiny.AppDeviceBridge.Calendar
```

```csharp
builder.UseAppDeviceBridge(
    bridge => bridge.AddCalendarBridge(),
    webApp => { /* … */ }
);
```

| Client | C# | TypeScript |
| --- | --- | --- |
| `ICalendarBridge` | `AddCalendarBridgeClient()` | `CalendarBridge` |

## Details

- **Platforms:** Android, iOS, Mac Catalyst, macOS and Windows.
- **Access:** `POST calendar/access` takes `ReadWrite` (the default), `ReadOnly` or `WriteOnly`. Write-only
  access (iOS 17+) is reported as `Restricted`.
- **Listing:** `GET calendar/events` requires `start` and `end`, at most 366 days apart. Paging works like
  contacts.
- **Reminders:** `reminderMinutes` counts minutes before the start.
- **Read-only fields:** attendees, the organizer and recurrence can be read but not written.
- **Read-only calendars:** writing to one returns `403 read_only`, and so does writing to a system calendar on
  Windows, which only allows writes to app-owned calendars.
- **Deleting:** `DELETE calendar/events/{id}?series=true` removes the rest of a recurring series rather than one
  occurrence.
- **Mac Catalyst, sandboxed macOS:** also need the `com.apple.security.personal-information.calendars`
  entitlement. Without it, access is denied without a prompt.

Every route answers `403 access_denied` until access has been granted.

## From the page

```ts
import { CalendarBridge } from "@shinyorg/appdevicebridge";

const calendar = new CalendarBridge();
await calendar.requestAccess({ access: "ReadWrite" });

const week = await calendar.getEvents(new Date(), new Date(Date.now() + 7 * 864e5), { limit: 50 });
for (const e of week.items) console.log(e.start, e.title);

const created = await calendar.createEvent({
    title: "Dentist",
    start: "2026-10-12T15:00:00-04:00",
    end: "2026-10-12T16:00:00-04:00",
    reminderMinutes: [30]
});
await calendar.updateEvent(created.id!, { location: "123 Main St" });
```

Event lists page with `offset` and `limit`; `hasMore` says whether to ask again.
