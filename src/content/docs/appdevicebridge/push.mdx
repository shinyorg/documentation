The push bridge registers and unregisters for push, gives the page the token and tags, raises token events, and can hand push payloads to the page or background.js. It's backed by Shiny.Push.

Android, iOS, Mac Catalyst, macOS and Windows. Linux has no push and answers `501`.

## Install and register

```bash
dotnet add package Shiny.AppDeviceBridge.Push
```

```csharp
builder.UseAppDeviceBridge(
    bridge => bridge.AddPushBridge(o => o.DispatchToWebApp = true),
    webApp => { /* … */ }
);
```

| Client | C# | TypeScript |
| --- | --- | --- |
| `IPushBridge` | `AddPushBridgeClient()` | `PushBridge` |

## Requests

The platform setup is Shiny.Push's: the `aps-environment` entitlement and the `remote-notification` background mode on Apple platforms, `google-services.json` on Android. How payloads reach background.js is on [Native Calls & Background](/appdevicebridge/background/).
