The geofencing bridge gives the page permissions, the regions it monitors, and their enter and exit transitions, delivered as `geofence.status` events while a page is open and to background.js otherwise. It's backed by Shiny.Geofencing.

Android, iOS, Mac Catalyst and Windows. Everywhere else every route answers `501`.

## Install and register

```bash
dotnet add package Shiny.AppDeviceBridge.Geofencing
```

```csharp
builder.UseAppDeviceBridge(
    bridge => bridge.AddGeofenceBridge(),
    webApp => { /* … */ }
);
```

| Client | C# | TypeScript |
| --- | --- | --- |
| `IGeofencesBridge` | `AddGeofencesBridgeClient()` | `GeofencesBridge` |
