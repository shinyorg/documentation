The geofencing bridge gives the page permissions, the regions it monitors, and their enter and exit transitions, delivered as `geofence.status` events while a page is open and to background.js otherwise. It's backed by Shiny.Geofencing.

Android, iOS, Mac Catalyst and Windows. Everywhere else every route answers `501`.

For more regions than the OS allows, or polygons rather than circles, see
[Document Geofencing](/appdevicebridge/document-geofencing/).

## Install and register

```bash
dotnet add package Shiny.AppDeviceBridge.Geofencing
```

```csharp
builder.UseAppDeviceBridge(
    bridge => bridge.AddGeofenceBridge(),
    webApp => { /* … */ }
);
```

| Client | C# | TypeScript |
| --- | --- | --- |
| `IGeofencesBridge` | `AddGeofencesBridgeClient()` | `GeofencesBridge` |

## From the page

Monitoring survives the page: transitions reach background.js when no page is open — see
[Native Calls & Background](/appdevicebridge/background/).

```ts
import { GeofencesBridge } from "@shinyorg/appdevicebridge";

const geofences = new GeofencesBridge();
const { access } = await geofences.requestAccess();
if (access !== "Available") return;

await geofences.onStatus(s => console.log(s.identifier, s.state));   // "Entered" | "Exited"
await geofences.startMonitoring({
    identifier: "office",
    latitude: 43.6532,
    longitude: -79.3832,
    radiusMeters: 200,
    singleUse: false,
    notifyOnEntry: true,
    notifyOnExit: true
});
```
