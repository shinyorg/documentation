## v1

### 1.5 - TBD

Initial Release. Shiny.UniversalHubs and Shiny.BluetoothLE.Hubs now ship from one repo with one version, so the first release follows BluetoothLE Hubs' 1.4 as 1.5.

<RN type="feature">Media channels over Wi-Fi: a WebSocket at `{Endpoint}/media`, opened with the `mediaToken` from the handshake reply and handed to the hub like an L2CAP media channel. Wire compatible: the reply's new fields are optional</RN>
<RN type="chore">Requires Shiny.BluetoothLE.Hubs 1.4 (media channels)</RN>
<RN type="fix">Connecting to a host that restarted (it listens on a new port) no longer fails until the client app restarts. When none of a discovered host's addresses answer, the client looks it up again by name over mDNS and retries where it is now. `UniversalHubClientOptions.HttpRediscoverTimeout` (3 seconds) sets how long it looks</RN>
