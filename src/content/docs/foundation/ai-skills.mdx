Every Shiny library has an AI skill that understands its APIs, patterns, and conventions. They all ship in a **single plugin** — install it once and every skill below is available. Your agent loads only the skill relevant to what you're building, so there's no cost to having them all installed.

## WebMCP: this site as agent tools

Skills help an agent while it writes your code. This site also helps an agent while it's browsing: every page on shinylib.net registers a set of read-only [WebMCP](https://github.com/webmachinelearning/webmcp) tools. An AI agent working in your browser tab can call them directly, so it gets real answers from these docs and from the skills above as structured JSON, instead of reading and clicking through pages.

| Tool | What it does |
|---|---|
| `search-docs` | Full-text search of the docs, optionally limited to one section (`client`, `controls`, `documentdb`, `blog`, …) |
| `read-page` | Returns a page's text in chunks, with headings and code blocks kept |
| `get-current-page` | Title, headings and related pages for the page that's open |
| `list-skills` | The Shiny skills, filtered by text or category, with the install commands |
| `get-skill` | One skill's full description, trigger keywords, docs link and `SKILL.md` links |
| `list-libraries` | Shiny libraries with a tagline, docs link and NuGet package ids |

The tools only read public content. They never change anything, and they load nothing in a browser that doesn't support WebMCP.

### Trying it

WebMCP is still experimental. To turn it on, open `chrome://flags/#enable-webmcp-testing` in Chrome (or `edge://flags/#enable-webmcp-testing` in Edge), set it to **Enabled**, and relaunch. Then open any page here, open the DevTools console, and run:

```js
const tools = await document.modelContext.getTools();
console.log(tools.map((t) => t.name));

const getSkill = tools.find((t) => t.name === 'get-skill');
console.log(JSON.parse(await document.modelContext.executeTool(getSkill, { name: 'bluetoothle' })));
```

Any agent that can reach the open tab can use these tools, whether that's a browser's built-in assistant or an extension. You can also drive them from a terminal agent such as Claude Code or GitHub Copilot CLI through a local relay. James Montemagno's [Adding WebMCP to a static Hugo site](https://montemagno.com/adding-webmcp-to-a-static-hugo-site-on-github-pages/) walks through that setup.
