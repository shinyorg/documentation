Every Shiny package referenced in this documentation, grouped by library. Versions and download counts
are pulled live from [nuget.org](https://www.nuget.org) when the page loads. **Latest version**
is the newest release, betas included; when that is a beta, the newest stable release is listed under it.
**Deprecated** packages (hidden by default - untick **Hide deprecated**) are still on nuget.org but no longer
maintained: packages from before Shiny (Acr.UserDialogs, Plugin.BluetoothLE, ...), Shiny v3/v4 packages, and packages
that were merged or renamed (Shiny.BluetoothLE.Hubs, the `*.Blazor` and `*.Linux` add-ons, Shiny.SqliteDocumentDb, ...).
Where something replaced one, **successor** links to it.
