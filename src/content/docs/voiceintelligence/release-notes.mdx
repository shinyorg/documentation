## 1.0 TBD
<RN type="feature">**`IVoiceIntelligence.ForgetShots(personIdentifier, shotIds)` removes selected utterances** (by `Speaker.Id`) belonging to an identity, the voice equivalent of the face API. Custom stores implement `IVoiceStore.RemoveShots`, which has a default implementation that throws. Based on the face version contributed by Jos Menhart ([@Josbourne2](https://github.com/Josbourne2)) ([#7](https://github.com/shinyorg/recogintelligence/pull/7))</RN>
<RN type="enhancement">**Windows (build from source):** on a Windows host, `Shiny.VoiceIntelligence.Maui` also targets `net10.0-windows10.0.19041.0`. The published package is built on macOS and does not include the Windows target yet. Thanks to Jos Menhart ([@Josbourne2](https://github.com/Josbourne2)) of [SoberCheck](https://www.sobercheck.nl) ([#1](https://github.com/shinyorg/recogintelligence/pull/1))</RN>
<RN type="feature">Initial release — on-device speaker (voice biometric) enrollment and recognition, built to the same architecture as Shiny.FaceIntelligence: a dependency-free core plus swappable embedder and store packages composed with `AddVoiceIntelligence`.</RN>
<RN type="feature">`IVoiceIntelligence` — `Enroll` / `Recognize` over mono PCM sample buffers, `CreateEnrollment`, `GetAll` and `Forget`, keyed on a caller-chosen `PersonIdentifier`. The library never opens a microphone; capture stays with the app.</RN>
<RN type="feature">`VoiceEnrollmentSession` — guided enrollment that measures each recording (duration, speech level, clipping, SNR) and keeps going until the voiceprints agree, with distance gates derived from the match threshold, bad-first-clip recovery, and best-subset storage when it runs out of attempts.</RN>
<RN type="feature">`Shiny.VoiceIntelligence.Onnx` — speaker embedder supporting both raw-waveform and 80-bin filterbank model inputs, auto-detected from the model's declared input rank, with a kaldi-compatible filterbank front end.</RN>
<RN type="feature">`Shiny.VoiceIntelligence.DocumentDb` / `.DocumentDb.Sqlite` — vector storage and nearest-neighbour search over Shiny.DocumentDb, with the vector dimension read from the embedder.</RN>
<RN type="feature">`Shiny.VoiceIntelligence.Maui` — `VoiceEnrollmentView`, a guided enrollment control with prompt list, countdown, dB-scaled VU meter marking the acceptance threshold, and an attempt ceiling that still stores the best usable subset. Records through the app-supplied `IVoiceRecorder` seam.</RN>
<RN type="feature">AOT- and trim-compatible across every package, with a source-generated `JsonSerializerContext` for the stored document type.</RN>
<RN type="feature">Automatic iOS / Mac Catalyst linker fix for ONNX Runtime's `_RegisterCustomOps` symbol, named so it coexists with the Face Intelligence equivalent in the same app.</RN>
