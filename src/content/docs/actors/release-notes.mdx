## 1.0.0 TBD

<RN type="feature">**Initial release.** Orleans-style virtual actors that run in one process anywhere .NET runs, including .NET MAUI and Blazor WebAssembly, and are AOT and trim clean. Source-generated proxies and registrations, turn-based concurrency with deadlock detection (across processes too), call timeouts, activation backoff, dead-letter observers, back pressure, ETag-checked state with named states and auto-save, event sourcing with snapshots, state and event migrations, typed and durable streams, timers and persistent reminders, call filters, request context and OpenTelemetry. Add-on packages: `Shiny.Actors.DocumentDb` (storage, with conflict-safe writes on every backend including IndexedDB, and tombstone purging), `Shiny.Actors.HttpServer` (remoting, with per-call and per-stream authorization, server-owned request context and SSE heartbeats), `Shiny.Actors.Jobs` (background reminders), `Shiny.Actors.Notifications` (reminder notifications, with upcoming occurrences scheduled ahead and tap routing to the actor), `Shiny.Actors.Discovery` (mDNS, with automatic advertising) and `Shiny.Actors.Testing` (fake time, seeding and inspection against any store).</RN>
