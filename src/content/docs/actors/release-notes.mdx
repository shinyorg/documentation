## 1.0.0 TBD

<RN type="feature">**Initial release.** Orleans-style virtual actors that run in one process anywhere .NET runs, including .NET MAUI and Blazor WebAssembly, and are AOT and trim clean. Source-generated proxies and registrations, turn-based concurrency with deadlock detection, ETag-checked state with named states and auto-save, event sourcing with snapshots, state and event migrations, typed and durable streams, timers and persistent reminders, call filters, request context and OpenTelemetry. Add-on packages: `Shiny.Actors.DocumentDb` (storage), `Shiny.Actors.HttpServer` (remoting), `Shiny.Actors.Jobs` (background reminders), `Shiny.Actors.Notifications` (reminder notifications), `Shiny.Actors.Discovery` (mDNS) and `Shiny.Actors.Testing`.</RN>
