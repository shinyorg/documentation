## .NET MAUI

Store state in SQLite through [Shiny.DocumentDb](/actors/state/#shinydocumentdb):

```csharp
builder.Services.AddShinyActors(actors => actors.UseDocumentDb(
    new SqliteDatabaseProvider($"Data Source={Path.Combine(FileSystem.AppDataDirectory, "actors.db")}")
));
```

The OS can kill a backgrounded app without warning. Either use [`[AutoSave]`](/actors/state/#auto-save)
(or `actors.UseAutoSave()` for every actor), so nothing ever lives only in memory, or flush when the app sleeps:

```csharp
protected override async void OnSleep() => await actorSystem.DeactivateAllAsync();   // ActorSystem from DI
```

- **Reminders while the app is suspended:** [`UseBackgroundReminders()`](/actors/reminders/#in-the-background).
- **Reminders on time even when the app is dead:** [`UseReminderNotifications()`](/actors/reminders/#on-time-even-when-the-app-is-dead).
- **Sharing actors with nearby devices:** [serve them over HTTP](/actors/remoting/) and [advertise them over mDNS](/actors/remoting/#finding-devices).

<Aside type="caution" title="SQLite on Android">
Pin a patched `SQLitePCLRaw` per platform, and don't add the plain `SQLitePCLRaw.lib.e_sqlite3` to an Android target.
See the note under [Shiny.DocumentDb](/actors/state/#shinydocumentdb).
</Aside>

## Blazor WebAssembly

Actors run in the browser too. Store state in IndexedDB through Shiny.DocumentDb. Because the IndexedDB store is
created by the container, call `UseDocumentDb()` with no arguments:

```csharp
builder.Services.AddSingleton<IDocumentStore>(sp =>
{
    var options = new IndexedDbDocumentStoreOptions
    {
        DatabaseName = "my-app",
        JsonSerializerOptions = new JsonSerializerOptions { TypeInfoResolver = ActorDocumentsJsonContext.Default },
        UseReflectionFallback = false
    };
    return new IndexedDbDocumentStore(options.MapActorDocuments(), sp);
});

builder.Services.AddShinyActors(x => x.UseDocumentDb());   // the IndexedDB store registered above
```

Reminders fire while the tab is open. A [remote client](/actors/remoting/#client) works from the browser as well,
as long as the server allows the page's origin.
